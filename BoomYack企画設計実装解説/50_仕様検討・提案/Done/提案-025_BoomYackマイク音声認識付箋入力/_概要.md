# 提案-025: BoomYack マイク音声認識による付箋直書き機能

## 1. 概要 (Overview)
BoomYackのキャンバス上で、マイク（音声入力）を使用して、**選択した付箋に直接テキストを流し込む**機能の追加を提案します。

## 2. 現状と課題 (As-Is)
- 現在、付箋へのテキスト入力はキーボードによる手動入力のみ。
- 思考のスピードにタイピングが追いつかない、またはハンズフリーでメモを取りたいというニーズに対応できていない。

## 3. 提案内容 (To-Be)
- **マイクデバイス連携**: ブラウザの `getUserMedia` および Web Speech API （またはより高精度なローカル音声認識エンジン）を使用。
- **選択付箋への書き込みロジック**:
    音声認識をボタンを使ってアクティブにすると非アクティブにするまでずっとマイクはオンになる。マイクがオンの限りOneOnetのマイクと同様終わったら自動で再起動し無限ループさせる。
    音声認識した結果が出たとき、選択中の付箋があればそこに書き込まれる(複数選択しているときはそのすべてにかきこまれる：使用用途はすべてに同じラベルを付けたいなど？)
    注意：現状、選択していない付箋内のテキストエリアやインプットエリアを編集中 (`input`, `textarea` フォーカス時)にしても付箋が選択状態にならないというバグがあり、今までは問題なかったが今回の機能で問題になるので付箋内のテキストエリアなどにフォーカスが当たったときも付箋を選択状にするよう修正する。
    
- **UI実装**:
    - キャンバスでも付箋でもコンテキストメニューにマイク起動を追加。SVGアイコンを使う。オンの時とオフの時で見た目を変える。コンテキストメニューのボタンには見た目のトグル機能や処理のトグル機能がないかもしれないがなければ実装する。すでにトグル機能のボタンはいくつかあるので最も優れているものを探して使う。
    

## 4. 期待される効果
- 入力速度の向上。
- 自然な発話によるブレーンストーミング（思考の言語化）の加速。

## 優先度の低いこと
- 録音中は対象の付箋が青色のオーラや波形アニメーションで強調表示される。（大規模な修正なしに簡単にできるならやってよい。しかし付箋CSSは複雑なので壊れそうならいったんやらない。）
