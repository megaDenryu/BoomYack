# 提案-021: コンテキストメニューUIの改善_バームクーヘン型多段配置

## 1. 概要
コンテキストメニュー（ノード周辺に表示されるボタン群）において、長文のテキストが収まるように面積を確保するための「バームクーヘン型多段配置UI」を導入する提案です。

## 2. 現状と課題（As-Is）
- 現在のコンテキストボタンはサイズが小さく、長い文字を入れるとテキストがはみ出したり読めなかったりする。
- ボタンを単に円状に配置するだけでは面積が稼げず、長い項目名（「区切り文字分解」など）を視認性良く表示できない。

## 3. 提案（To-Be）
- **多段バームクーヘン型レイアウト**:
  - 中心ノードの周りを正多角形2つで囲まれた「バームクーヘンをN分割した台形」のような形状のボタンで取り囲む。
  - それを複数層（多段）に積み重ねるUIとする。
- **実装例（グリッドベース案）**:
  - 3×3のマス目を持つ正方形ボタンを中心に配置し、クリックするとその周囲を8個の正方形が取り囲む。
  - さらに外周を5×5（つまりさらに16個の正方形）で取り囲ませることで、長文を格納する面積を持ったボタンを構築する。

## 4. 影響範囲
- `app-ts/src/BoomYack/` 内のUIコンポーネント（コンテキストメニュー描画部分）
- 座標計算・レイアウトロジック

## 5. 次のステップ
