# 多段グリッドコンテキストメニュー 詳細UI・コンポーネント設計

「バームクーヘン型」という抽象的な表現を、DOM構造（SengenUI）において破綻なく、かつ柔軟に描画・拡張できる**「グリッドベース多段メニュー（Grid-based Radial Menu）」**として具体化します。

## 1. 概念モデル（バームクーヘンからグリッドへの落とし込み）

円形や台形のクリック判定をHTML/CSS（DOM）で構築するのは `clip-path` 等の複雑な処理を要し、内部に長文のテキストを配置するのも困難です。
これを解決するため、**CSS Grid Layout**をベースにした階層構造の升目グリッドを採用します。

### 座標とセルの配置（レイヤー構造・7x7グリッド）

クリック地点（または対象付箋の特定のアンカーポイント）を中心 `(4, 4)` とする 7x7 のグリッドを描画します。

*   **第0層（Center / 1×1マスの中心）**:
    *   中心(X:4, Y:4)。デフォルトは空洞（対象のノード本体を視認・操作できるようにするため）。
    *   **オプション**: 中央を巨大な「決定」「追加」「閉じる」などの【センターボタン】として扱うモードを持たせる。
*   **第1層（周囲8マスレイヤー）**:
    *   X:3〜5, Y:3〜5の枠。中心を囲む8つのセル。
    *   **用途**: 大分類のカテゴリ（例：「AI操作」「付箋操作」「設定」など短いラベル）
*   **第2層（外周16マスの拡張レイヤー）**:
    *   それより外側（X:1〜2, 6〜7などの領域）。
    *   第1層のボタンと**物理的に重ならない領域**に配置され、隣接マスを繋げて（`span 2`など）横幅を確保する。
    *   **用途**: 長文が格納される実際のアクションボタン（例：「✂️ 区切り文字分解」など）

### 2つの利用モードのサポート

用途やユーザーの設定に応じて、両方のレイアウトを利用できる「モード（State）」を持たせます。

1. **パターンA（常時表示モード / Static）**
   - 2階層目のボタン（長文）を最初から全てオープンにした状態で表示する。
   - 一目でアクションが見通せ、1クリックで即座に機能が実行可能。
2. **パターンB（クリック・入れ子展開モード / Click-Expand）**
   - 開いた当初は第1層メニュー（大分類）だけが表示される。
   - ユーザーが第1層のボタンを**クリック**するとアニメーション付きで関連する第2層メニューが表示・展開される。
   - ※ ホバー（マウスオーバー）トリガーだと対象外にマウスが逸れた際に消えてしまって操作性が悪化・意味不明になるため、**「クリックによって状態を固定（トグル）する」** 挙動を正解とする。

## 2. コンポーネント設計（SengenUI仕様）

`LV2HtmlComponentBase` を継承したクラスを定義します。

### `多段グリッドコンテキストメニュー` クラス
*   **役割**: メニュー全体のライフサイクル管理、開閉状態の保持、表示モード切替。
*   **スタイル提案**:
    ```css
    .grid-context-menu {
        display: grid;
        grid-template-columns: repeat(7, 64px); /* 正方形セルの幅 */
        grid-template-rows: repeat(7, 64px);    /* 正方形セルの高さ */
        gap: 6px;
        pointer-events: none; /* 空白領域はクリック貫通させる */
    }
    ```

### `メニューセル` クラス
*   **役割**: 各ボタンの振る舞い。テキストの表示、アイコンの配置、ホバー時の子階層（第2層）展開のトリガー。
*   **プロパティ**:
    *   `GridX` (1〜5), `GridY` (1〜5): CSSの `grid-column`, `grid-row` に直結する座標。
    *   `階層` (1 or 2)
    *   `親セルID` (第2層の場合、どの第1層セルから派生したか)
*   **動作**:
    *   デフォルトでは `pointer-events: auto;`
    *   ガラスモーフィズム（半透明背景 ＋ `backdrop-filter: blur`）を用いることで、下にあるキャンバスの視認性を損なわないモダンなデザイン。

## 3. 展開ロジックの具体例

1.  **初期表示**:
    付箋を右クリックしてコンテキストメニューを呼ぶ。
    第1層の8セル（`GridX: 2〜4, GridY: 2〜4` の中央以外）を描画する。
2.  **ホバー展開**:
    ユーザーが「右サイドの第1層マス（X:4, Y:3）」にホバーする。
    そのマスに紐づくサブメニュー（第2層）が「さらに右（X:5, Y:2〜4の範囲）などにアニメーション付き（FadeInなど）で出現する。
3.  **アクション実行**:
    第2層の「区切り文字分解」セルをクリックすると、`AiOperationService` が呼ばれ、メニュー全体が `dispose()` される。

## 4. UIデザイン・スタイル（CSS）要件

*   **ボタン形状**: 角丸 (`border-radius: 6px;`)、微微なドロップシャドウで浮遊感を演出。
*   **状態変化**: ホバー時に微妙にスケールアップ（`transform: scale(1.05);`）、またはボーダーの色がプライマリカラー（アクセントカラー）に発光するエフェクト。
*   **長文対応**: 第2層のセルは、隣接するマスを `grid-column: span 2;` のように結合して、横幅240pxなどの広い面積を確保できるように自動伸縮機能（またはSpan設定パロメータ）を持たせる。これにより提案-021の**「長文項目を視認性良く表示する」**という最大の目的を達成する。
