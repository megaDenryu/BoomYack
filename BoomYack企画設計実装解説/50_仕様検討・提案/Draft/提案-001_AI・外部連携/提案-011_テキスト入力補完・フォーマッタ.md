# 提案-011: テキスト入力補完とインテリジェント・フォーマッタ

## 1. 現状 (Current State)
- テキストエリア(`textarea`)は標準的な挙動のみ。
- カッコのペアリングやオートインデントなどの支援機能がない。

## 2. 問題点・課題
- **入力効率**: 付箋へのメモ書き時、コードや構造化テキストを書く際に手動での整形が面倒。
- **可読性**: JSONやMarkdownを含むテキストが見づらい。

## 3. 提案内容
テキスト入力体験（DX）を向上させる「入力補完」と「自動フォーマット」機能を実装する。

### 3-1. 自動補完機能 (Auto-Completion)
- **括弧のペアリング**: 
    - `{` 入力 -> `{}` を挿入し、カーソルを中央へ。
    - `[` -> `[]`, `"` -> `""` なども同様。
- **改行時のインデント**:
    - `{` の直後でEnter -> 改行 + インデント + 閉じ括弧の行を作成。
    ```text
    {
        | (cursor)
    }
    ```

### 3-2. コードブロック認識とハイライト (野心的目標)
- テキスト内にトリプルバッククォート(```)やJSONライクな構造を検出した場合、単なるテキストエリアではなく、簡易的なコードエディタ（またはハイライト表示）として振る舞うモードを用意する。
- **実装案**: 
    - `textarea` オーバーレイ方式、または `contenteditable` への移行（難易度高）。
    - SengenUI的には `textarea` のまま、背景にハイライト用のHTMLを重ねる手法が現実的か。

### 3-3. 設計憲法・適合チェック
- [x] DOM操作: React/SengenUIのイベントハンドラ内で完結させる。
- [ ] パフォーマンス: 入力ごとの正規表現判定が重くならないよう注意。

## 4. 影響範囲
- `StickyNoteView` (付箋View) のテキスト入力部分。
- 新規: `TextFormatterService` (ロジック分離)。

## 5. 代替案
- **Monaco Editor埋め込み**: 機能は強力だが、付箋一つ一つに埋め込むには重すぎる。自前での軽量実装を選択。
