# 提案-012: UI/UX 設計検討

## 1. ユーザーアクションフロー
1. ユーザーがキャンバス上で起点となる「ノード」を選択する。
2. 選択されたノードの横に、小さな「✨ AI (Expand)」ボタンがホバー表示される（または右クリックのコンテキストメニューから選択）。
3. ボタンをクリックすると、簡単なプロンプト入力欄と「自動生成」ボタンを備えたポップオーバーが表示される。
   - デフォルトは「この内容を深掘りして」というモード。
   - ユーザーが手動で「AとBの違いについて」のように指示を足すことも可能。
4. 「自動生成」を実行すると、ローディングインジケーター（スピナー等）がノード付近に表示される。

## 2. 生成結果のロードとプレビュー
1. AIが生成を完了すると、**仮配置状態（半透明、または色付きの点線枠など）** で新しいノードとエッジがキャンバスに出現する。
2. 画面下部に「採用 (Accept) / まとめて破棄 (Reject)」のフローティングバーが表示される。
3. ユーザーが内容を確認し：
   - 「採用」を押せば正式なノードとして確定（Undoスタックに積まれる）。
   - そのまま一部のノードだけ手動で消すことも可能。
   - 「破棄」を押せば生成されたノード群が一括で消滅する。

## 3. UIコンポーネントへの要件
- **ホバーメニュー**: ノードコンポーネント(`CardNode` 等)への拡張。
- **仮配置ステート**: `GraphNode` に `isDraft: boolean` を追加し、スタイルを切り替える機能。
- **一括操作バー**: キャンバスに対するオーバーレイUI。
