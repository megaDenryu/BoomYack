# 提案-012: グラフ拡張生成機能 (AI続きを書いて)

## 1. 概要
選択したノードを起点として、AIが文脈を読み取り、後続のグラフ（ノードとエッジ）を自動生成・接続する機能。
ユーザーの思考のボトルネックを解消し、「アイデアの爆発的な展開」を支援します。

## 2. 設計ドキュメント・資産
本提案は以下のドキュメントによって詳細化されています。

- **[UI/UXモックアップ (HTML)](./UI%E3%83%A2%E3%83%83%E3%82%AF%E3%82%A2%E3%83%83%E3%83%97_%E3%82%B0%E3%83%A9%E3%83%95%E6%8B%A1%E5%BC%B5.html)**: 実際の操作感を体験できるプロトタイプ（ライトモード）。
- **[01_UI・UX設計検討](./01_UI%E3%83%BBUX%E8%A8%AD%E8%A8%88%E6%A4%9C%E8%A8%8E.md)**: 発光ボタン、パーティクル演出、Draft状態のビジュアル仕様。
- **[02_技術的深掘り](./02_%E6%8A%80%E8%A1%93%E7%9A%84%E6%B7%B1%E6%8E%98%E3%82%8A_%E7%8A%B6%E6%85%8B%E7%AE%A1%E7%90%86%E3%81%A8LLM%E3%83%97%E3%83%AD%E3%83%B3%E3%83%97%E3%83%88.md)**: Draftライフサイクル、コンテキスト抽出、並行性制御。
- **[03_UI状態遷移・SengenUI実装設計](./03_UI%E7%8A%B6%E6%85%8B%E9%81%B7%E7%A7%BB%E3%83%BBSengenUI%E5%AE%9F%E8%A3%85%E8%A8%AD%E8%A8%88.md)**: HTMLモックを基にした、SengenUIの世界観におけるステートマシン・階層構造の定義。

## 3. 現状と課題の整理
### 現状
- 手動操作のみで、思考のスピードに対して入力負荷が高い。
### 解決策
- マジックボタンによるAI自動生成。
- 「仮配置（Draft）→ レビュー → 確定」の3ステップワークフローによる品質担保。

## 4. 課題・残検討事項
- **座標決定**: 提案-015「自動レイアウト」との統合が必要。
- **プロンプト詳細**: ジャンル（ロジカルシンキング、創作、技術解説など）に応じた微調整。

# ユーザーレビューと対応

> とてもいい機能。しかしまだ検討しなければならないことが多い。
> まずUIの見た目をどうするのかなどの検討が少ないのでまだイメージがわかない。

**【AIエージェントの対応】**
- **UIモックアップの作成**: HTML1枚（`UIモックアップ_グラフ拡張.html`）で、ボタンの挙動、パーティクル演出、仮配置状態の視覚効果を実装しました。ブラウザで開いて体験いただけます。
- **インタラクションの定義**: 01番のドキュメントで、「魔法感」と「コントロール権（Accept/Reject）」を両立させるインタラクションを詳細化しました。
- **実装の具体化**: 02番のドキュメントで、一時的なノード（Draft）をどうシステムが管理するかという、より実装に近い部分を深掘りしました。
