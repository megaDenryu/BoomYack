# ディスカッション

## 2026-02-25
- ユーザーより「BoomYackの付箋の中で文字に赤線が引かれる」「付箋の色が保存されない」と2件の報告を受け起票。
- **原因調査（赤線問題）**:
  - ` 自動リサイズ付箋View2.ts ` の基底として呼ばれている ` 自動リサイズテキストエリア.ts ` にて、SengenUIの `TextAreaC` に対するオプションとして `spellcheck` の無効化がなされていなかった。
- **原因調査（色未保持問題）**:
  - ` 付箋データ ` （不変データクラス）や `I付箋JSON`（シリアライズフォーマット）の中に「設定情報」（色、サイズ等を保持する `付箋設定状態` オブジェクト）のフィールドがそもそも無かった。
  - セーブ時に ` CanvasItemFactory.ts ` 等を経由して保存されるが、UI側の `_設定状態` が JSON へと送られておらず破棄されていた。
- **修正対応**:
  - 両バグともに解決済として修正完了。
  - ` CanvasItemFactory.ts ` では、データロード時に ` data.設定状態 ` の呼び出しを用いてプロパティ復元にまで対応させた。
