# 提案-018: 自律型AIエージェントによるBoomYack操作 (LLMHumanBody活用)

## 1. 現状
- 既存の `api/LLM/エージェント/会話用エージェント/自立型Ver1` に、人間的な振る舞い（思考、感情、エネルギー）を持つ `LLMHumanBody` が実装されている。
- しかし、これらは現在のBoomYackとは連携していない。

## 2. 問題点・課題 (Motivation)
- **ツールの孤独化**: ユーザーは一人で黙々とグラフを作る。壁打ち相手がいない。
- **資産の未活用**: 既に存在する高度なエージェント基盤 (`LLMHumanBody`) が使われていない。

## 3. 提案内容
既存の `LLMHumanBody` をBoomYackに住まわせ、ユーザーのパートナーとして活動させる。

### 3-1. 役割 (Role)
- **Advisor**: グラフの構造についてアドバイスする（「ここ、循環参照になってませんか？」）。
- **Operator**: ユーザーの自然言語指示を受けてグラフを操作する（「全体を整理して」「○○についてのノードを追加して」）。
    - 提案-012等の機能のトリガー役となる。
- **Chat**: 単なる雑談相手。

### 3-2. 実装方針
1. **Bodyの拡張**:
    - `I表現機構` (口) に加え、`I操作機構` (手) を実装する。
    - `手.操作する(Action)`メソッドを通じて、WebSocket経由でクライアントにコマンド (`ADD_NODE`, `LAYOUT`, etc.) を送信する。
2. **接続**:
    - Server起動時、ユーザーごとに `LLMHumanBody` インスタンスを生成（または永続化から復元）。
    - クライアントからのチャットメッセージを `耳` (Input) に流す。
3. **視覚化**:
    - BoomYack上にLive2Dまたは立ち絵を表示し、エージェントの状態（思考中、発話中、エネルギー切れ）を可視化する（既存の立ち絵システム活用）。

### 3-3. 既存コードの活用
- `LLMHumanBody.py`: そのまま利用。
- `脳内思考プロセス`: グラフ操作に関する思考ができるようにプロンプトやActionCandidateを拡張する。

## 4. 影響範囲
- Server: エージェント常駐プロセスの管理。
- Client: キャラクター表示UI、チャットUI。

## 5. ロードマップ
- まずは `提案-004` (外部連携基盤) が必須。
- その上で、単純なチャットボットとして導入し、徐々に「グラフ操作権限」を与えていく。
