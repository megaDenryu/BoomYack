# 提案-002: ショートカットキー実装の提案

## 1. 現状 (Current State)
`グラフ操作マニュアル` にドラフトとして記載されていましたが、以下のショートカットキーは現在未実装です。
- **削除:** `Delete` キー
- **全選択:** `Ctrl + A`

## 2. 問題点・課題 (Problem / Motivation)
- **ユーザビリティの低下**: 基本的なグラフ操作において、キーボードショートカットがないことは操作性を損ないます。
- **標準的な期待**: ユーザーはこれらの操作を直感的に期待します。

## 3. 提案内容 (Proposed Solution)
`CanvasView` または `GlobalInputManager` にキーボードイベントリスナーを追加し、以下の機能を実装します。

### 3-1. 実装仕様
- **Delete / Backspace**: 
    - 現在選択中のアイテム（付箋・矢印）をすべて削除する。
    - 注意: テキスト編集中 (`input`, `textarea` フォーカス時) は発火しないこと。
- **Ctrl + A**:
    - キャンバス内のすべての配置物を選択状態にする。
    - `selectionManager.全て選択()` のようなメソッドを追加する。

### 3-2. UI/UX設計案 (UI Design)
- 画面上の変更はなし。
- 削除実行時に確認ダイアログを出すかは要検討（現在は出さない仕様）。

### 3-3. 設計憲法・適合チェック (Constitution Check)
- [x] DOM操作を直接行っていないか？ -> イベントリスナー登録のみ
- [x] LV2コンポーネントを継承していないか？ -> はい

## 4. 影響範囲 (Impact)
- `CanvasView.ts`
- `配置物選択機能集約.ts`

## 5. 代替案 (Alternatives)
- 特になし。必須機能と考えられる。
