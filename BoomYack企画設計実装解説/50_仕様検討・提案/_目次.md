## ワークフロー

```
新規作成 → Draft/ → (承認・実装開始) → InProgress/ → (全Phase完了) → Done/
```

各ステップの定義:
- **Draft/**: 検討中・未承認。実装に入っていない提案
- **InProgress/**: 承認済み・実装中。部分完了（Phase途中）も含む
- **Done/**: 全Phaseが完了しコミット済みの提案

## 提案書フォーマット

各提案は**フォルダ**として管理する。複雑さに応じて内部ファイルを追加できる。

### シンプルな提案（Draft等）

```
Draft/提案-XXX_タイトル/
  _概要.md               ← 提案全体の要約、結論、最新仕様。タグやステータスもここで管理。
  _ディスカッション.md    ← ユーザーレビューや議論の履歴。
  01_詳細仕様.md          ← (必要に応じて) UI設計やアーキテクチャなどの詳細分割ファイル群
```

### 複数Phaseを持つ提案（InProgress）

```
InProgress/提案-XXX_タイトル/
  _概要.md              ← 現状・問題点・影響範囲マトリクス・代替案
  _ディスカッション.md   ← レビューや意思決定プロセス履歴
  _進捗.md              ← Phase別完了状況とcommit hash
  01_UI設計.md          ← 関連する詳細ファイル
  Phase0_タスク名.md    ← 各Phaseの実装詳細
  ...
```

`_概要.md`のfrontmatter:

```yaml
---
type: Proposal
status: Draft | InProgress | Done
created: YYYY-MM-DD
updated: YYYY-MM-DD
progress:
  phase0: done | pending
---
```
