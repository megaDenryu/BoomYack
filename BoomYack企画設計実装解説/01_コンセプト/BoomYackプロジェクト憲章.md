# BoomYackプロジェクト憲章

> [!abstract] 公理：思考の構造化と可視化の融合
> BoomYackは、テキストとグラフ構造をシームレスに行き来し、人間とAIが「構造」を通じて対話するためのインターフェースである。

## 概要
BoomYackは、Miroのような無限キャンバス上でノード（付箋）とエッジ（矢印）を用いてアイデアやロジックを可視化するグラフエディタです。
単なるお絵描きツールではなく、構成されたグラフをJSONデータとして出力し、AIエージェントの入力としたり、逆にAIエージェントが出力した構造化データを可視化・修正するためのプラットフォームとして機能します。

## コアバリュー
### 1. Structure First (構造第一主義)
テキストの羅列ではなく、意味のつながり（エッジ）と情報の塊（ノード）を第一級市民として扱います。これにより、物語のプロットラインやプログラムのフローチャートを直感的に操作可能です。

### 2. AI Friendly (対AI親和性)
内部データ構造はAIが理解・生成しやすいJSONフォーマットを前提としています。
- **Output:** 人間が描いたグラフ → JSON → AIが解釈
- **Input:** AIが考えた構造 → JSON → BoomYackで可視化

### 3. Obsidian-like Freedom (ローカルファーストと自由度)
特定のプロプライエタリなクラウドに閉じ込めるのではなく、ローカルファイルシステムとの親和性を重視します。
- ローカルへのJSON保存・読み込み
- Gitによるバージョン管理の親和姓（将来構想）
- Obsidianのようなナレッジベースツールとしての側面

## ターゲットユーザー

- AIエージェントの思考プロセスを可視化・デバッグしたい開発者
- マインドマップを超えた自由な発想整理を行いたいクリエイター
