# 音声認識入力仕様

BoomYackのキャンバスおよび付箋上で、マイク（音声入力）を使用して、選択した付箋に直接テキストを流し込む機能の仕様です。

## 1. 概要
ユーザーの発話をリアルタイムでテキスト化し、キャンバス上で選択されている付箋のテキストエリアに自動的に入力します。連続的な音声入力（無限ループ入力）をサポートしています。

## 2. 起動・停止
- **UIトリガー:** 
    - キャンバスまたは付箋のコンテキストメニュー内「その他」カテゴリにある **「マイク入力」** ボタン。
- **動作:** 
    - クリックすることで録音状態をトグル（ON/OFF）します。
    - **ONの時:** アイコンが赤色（マイクON）に変わり、ボタンの背景色が強調されます。
    - **OFFの時:** アイコンが通常の色（マイクOFF）に戻ります。

## 3. 音声認識ロジック
- **サービス:** `VoiceRecognitionService` が管理。
- **特性:**
    - ブラウザの Web Speech API を使用。
    - 音声認識は「連続モード (`continuous: true`)」かつ「中間結果あり (`interimResults: true`)」で動作します。
    - 認識が一度終了しても、サービスがONである限り自動的に再起動し、無限ループを実現します。
- **書き込み:**
    - 音声認識結果が「確定」したタイミングで、その時点の `selectionManager` が保持する「選択中の付箋（複数可）」に対してテキストを設定します。
    - 空白のみの結果は無視されます。

## 4. UI・演出
- **トグルボタン:** `SelectableGridCell` を使用し、内部状態に基づいた見た目の切り替えを宣言的に行っています。
- **グローバル状態:** `VoiceRecognitionService` は Observable な状態を持ち、複数のUIコンポーネント（キャンバスのメニュー、各付箋のメニュー）に対して同時に状態変化を通知します。
- **録音中インジケータ:** キャンバスの右下に、録音中であることを示す視覚的なフィードバックが表示されます。

## 5. 関連コンポーネント
- **サービス:** `音声認識サービス.ts`
- **UI:** `CanvasView.ts`, `自動リサイズ付箋View.ts`, `多段格子コンテキストメニュー.ts`, `GridCell.ts` (SelectableGridCell)

## 6. 特記事項
- **フォーカス連動:** テキストエリアや入力エリアにフォーカスが当たった際、対象の付箋が自動的に「選択状態」になるよう修正されており、音声入力が即座に反映されるようになっています。
