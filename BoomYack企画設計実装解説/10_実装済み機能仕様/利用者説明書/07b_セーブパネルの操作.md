# 07b セーブパネルの操作

状態: 草案(オーナー未承認)。索引と語の定義は [[利用者説明書 - 索引]]。

この文書は、セーブパネルの開き方と閉じ方、並んでいるもの、新規保存、上書き保存と Ctrl+S、読み込み、名前の変更、削除とセーブパネルのゴミ箱を書く。保存先「サーバー」で保存を断られたときの振る舞いは [[07c_サーバーとのやり取り]] に、データが消える条件は [[07d_データが消える条件の一覧]] に書く。

## 開き方と閉じ方

- 利用者がボードのメニューの保存のアイコン(右)を押すと、BoomYack はセーブパネルを開く。
- セーブパネルの現在名が決まっていないときに利用者が Ctrl+S を押しても、BoomYack はセーブパネルを開く。
- セーブパネルは、ボードの領域の真ん中に、幅 400px の暗い色の枠として出る。セーブパネルの外側は、半透明の黒い覆いで覆われる。
- セーブパネルは、0.2 秒かけて現れる。
- 利用者が右上の「×」を押すか、外側の黒い覆いを押すと、セーブパネルは閉じる。
  - 閉じる操作をした時点で、覆いとセーブパネルは操作を受け付けなくなる。
  - 覆いとセーブパネルは、0.2 秒かけて薄れて消える。
- セーブパネルが開くたびに、BoomYack は今の保存先の一覧を読み直す。

## 並んでいるもの

セーブパネルには、上から次の順に並ぶ。

1. 見出し「セーブ/ロード」と閉じるボタン「×」
2. 「保存先」と、「ローカル」「サーバー」の2つのボタン。今の保存先のボタンが強調される
3. 「現在のキャンバス名」と、セーブパネルの現在名。現在名が決まっていないときは「（未保存）」と出る。現在名が決まっているときだけ、右に「上書き保存」ボタンが出る
4. 「新規保存」と、名前の入力欄(空のとき「キャンバスの名前を入力...」と薄く出る)と「新規保存」ボタン
5. 「保存データ一覧」と、今の保存先の保存済みのボードの一覧。各行には、保存済みのボードの名前、最後に保存した日時、「json」ボタン、ゴミ箱へ入れるボタン(ゴミ箱の絵)が並ぶ。一覧が空のときは「保存データがありません」と出る
6. 「読込」ボタン
7. セーブパネルのゴミ箱のボタン。セーブパネルのゴミ箱に何かが入っているときだけ出る。ボタンの振る舞いは、下の「削除とセーブパネルのゴミ箱」に書く

- 一覧の並び順は、保存先が返した順のままである。BoomYack は一覧を並べ替えない。
- 利用者が一覧の行を押すと、BoomYack はその行を選び、強調する。

## 新規保存

1. 利用者が名前を入力して「新規保存」ボタンを押す。BoomYack は名前の前後の空白を取り除く。名前の入力欄で利用者が Enter キーを押しても、保存されない。
2. 名前が空のとき、BoomYack はお知らせ「保存名を入力してください」を出し、保存しない。
3. 今の保存先の一覧に同じ名前の保存済みのボードがあり、その保存済みのボードがセーブパネルのゴミ箱に入っていないとき、BoomYack はお知らせ「同名のキャンバスが既に存在します」を出し、保存しない。
4. それ以外のとき、BoomYack は次の順に処理する。
   1. ボードを、入力した名前で今の保存先へ保存する。
   2. 一覧で選んでいた行の選択を外す。
   3. 一覧を読み直す。
   4. お知らせ「保存しました」を出す。
   5. セーブパネルの現在名を、入力した名前にする。
   6. 名前の入力欄を空にする。

- 保存先が「サーバー」のときに保存を断られた場合の振る舞いは、[[07c_サーバーとのやり取り]] に書く。

## 上書き保存と Ctrl+S

この節を、Ctrl+S の保存の動きの正本とする。

- 利用者が「上書き保存」ボタンを押すと、BoomYack は次の順に処理する。
  1. ボードを、セーブパネルの現在名で今の保存先へ保存する。
  2. 一覧を読み直す。
  3. お知らせ「(現在名)を上書き保存しました」を出す。
- セーブパネルの現在名が決まっているときに利用者が Ctrl+S を押すと、BoomYack は次の順に処理する。
  1. ボードを、現在名で今の保存先へ保存し始める。
  2. 保存の終わりを待たずに、お知らせ「(現在名)を上書き保存しました」を出す。
  3. 保存先「サーバー」では、その後にサーバーの結果のお知らせが出る。
- Ctrl+S では、BoomYack は一覧を読み直さない。
- Ctrl+S が効く場所は、[[05_キー操作と元に戻す]] に書く。
- 保存先「ローカル」では、同じ識別子の保存済みのボードがあれば、BoomYack は確認せずに置き換える。
- 保存先「ローカル」への保存が失敗しても、BoomYack は成功のお知らせを出す([[90_オーナーの判断事項]] の42番)。

## 読み込み

1. 利用者が一覧の行を押して選び、「読込」ボタンを押す。
2. 行を選んでいないとき、BoomYack はお知らせ「読み込むデータを選択してください」を出す。
3. 選んだ保存済みのボードがセーブパネルのゴミ箱に入っているとき、BoomYack はお知らせ「削除予定のデータです。復元してから読み込んでください」を出す。
4. それ以外のとき、BoomYack は次の順に処理する。
   1. ボードの配置物をすべて取り除く。
   2. 選んだ保存済みのボードの配置物と表示位置に置き換える。表示の倍率は変えない。
   3. セーブパネルの現在名を、選んだ保存済みのボードの名前にする。
   4. セーブパネルを閉じる。
   5. お知らせ「読み込みました」を出す。

- 読み込む前の変更が保存されていなくても、BoomYack は確認を出さない。
- BoomYack は、読み込むときに配置物を取り除くが、配置物の選択は外さない([[90_オーナーの判断事項]] の44番)。
- 読み込んだ後の元に戻す操作の振る舞いは、[[05_キー操作と元に戻す]] の「元に戻す操作の注意点」に書く。
- 読み込みに失敗したときの振る舞いは、[[90_オーナーの判断事項]] の24番で扱う。
- 一覧で選んだ行は、利用者が保存先を切り替えても選ばれたまま残る([[90_オーナーの判断事項]] の56番)。
  - 切り替えた先に同じ識別子の保存済みのボードがあると、利用者が「読込」を押したとき、BoomYack はその別の保存済みのボードを読み込む。
  - 同じ識別子の保存済みのボードが無いと、ボードの中身は変わらないまま、セーブパネルの現在名が決まっていない状態(「（未保存）」)になり、お知らせ「読み込みました」が出る。

### 保存先「ローカル」の、決まった形に合わない保存済みのボード

この節を、決まった形に合わない保存済みのボードの扱いの正本とする。仕組みは [[90_オーナーの判断事項]] の41番と54番に書く。

- 保存先「ローカル」で、中身が決まった形に合わない保存済みのボードを BoomYack が読むと、BoomYack はその保存済みのボードを保存先から消す。
- BoomYack は、一覧を読み直すときに、一覧のすべての保存済みのボードを読む。このため、形に合わない保存済みのボードは、一覧を読み直すだけで消える。
- BoomYack が一覧を読み直すのは、次のときである。
  - セーブパネルを開いたとき
  - 保存先を切り替えたとき
  - 「新規保存」「上書き保存」「名前の変更」で保存した後
  - ファイルをボードへドロップしたとき
- 利用者が「json」ボタンを押したときも、BoomYack はその行の保存済みのボードを読む。
- 保存先「ローカル」に、知らない種類の配置物を持つ保存済みのボードが1つでもあると、一覧を読み直すたびに一覧全体が空になり、「保存データがありません」と出る。

## 名前の変更

1. 利用者が「現在のキャンバス名」に出ている名前をダブルクリックすると、BoomYack は名前を入力欄に変え、今の名前の全体を範囲選択した状態で、その入力欄をキー入力の受け先にする。セーブパネルの現在名が決まっていないときは、入力欄に変わらない。
2. 利用者が新しい名前を入れて Enter キーを押すか、入力欄の外を押すと、変更が確定する。利用者が Escape キーを押すと、変更をやめる。
3. 新しい名前が空のとき、または今の名前と同じときは、BoomYack は変更をやめる。
4. 今の保存先の一覧に同じ名前の保存済みのボードがあり、その保存済みのボードがセーブパネルのゴミ箱に入っていないとき、BoomYack はお知らせ「同名のキャンバスが既に存在します」を出し、変更をやめる。
5. それ以外のとき、BoomYack は次の順に処理する。
   1. ボードを、新しい名前で今の保存先へ保存する。
   2. 今の保存先の一覧から、古い名前の保存済みのボードを名前だけで探し、セーブパネルのゴミ箱へ入れる。このとき BoomYack は、「元に戻す」ボタン付きのお知らせ「「(古い名前)」を削除しました」を出す。
   3. セーブパネルの現在名を、新しい名前にする。
   4. 一覧を読み直し、お知らせ「"(古い名前)"を"(新しい名前)"にリネームしました」を出す。

- 名前の変更で新しい名前で保存されるのは、保存済みのボードではなく、今ボードにある中身である。
- 古い名前の保存済みのボードは、セーブパネルのゴミ箱に入るだけで、その場では消えない(下の「削除とセーブパネルのゴミ箱」を参照)。
- 保存先「サーバー」で新しい名前の保存を断られたときの振る舞いは、[[07c_サーバーとのやり取り]] に書く。
- 次のときにどの保存済みのボードがゴミ箱に入るかは、[[90_オーナーの判断事項]] の38番で扱う。
  - 新しい名前と古い名前から作った識別子が同じになるとき
  - 古い名前と同じ名前の保存済みのボードが一覧に2つあるとき
  - 別の保存先から読み込んだボードの名前を変えたとき

## 削除とセーブパネルのゴミ箱

この節を、セーブパネルのゴミ箱の振る舞いの正本とする。

- 利用者が一覧の行のゴミ箱へ入れるボタンを押すと、BoomYack は次の2つを行う。
  - その保存済みのボードをセーブパネルのゴミ箱に入れ、一覧から見えなくする。
  - 「元に戻す」ボタン付きのお知らせ「「(名前)」を削除しました」を 5 秒出す。お知らせの「元に戻す」ボタンは、ボードの元に戻す操作とは別の物である。
- 利用者がお知らせの「元に戻す」ボタンを押すと、BoomYack はその保存済みのボードをゴミ箱から戻し、お知らせ「「(名前)」を復元しました」を出す。
- セーブパネルのゴミ箱のボタンには、セーブパネルのゴミ箱に入っている数が小さく出る。この数は、保存先「ローカル」と「サーバー」の分を合わせた数である。
- 利用者がセーブパネルのゴミ箱のボタンを押すと、BoomYack は次の2つを行う。
  - 一覧を、ゴミ箱の中身(今の保存先の分だけ)に切り替える。ゴミ箱の中身が空のときは「ゴミ箱は空です」と出る。
  - ボタンの文字を「← 戻る」にする。
- 利用者がゴミ箱の各行の「↩」ボタンを押すと、BoomYack はその保存済みのボードをゴミ箱から戻す。
- 利用者がセーブパネルを閉じると、一覧はゴミ箱でない方に戻る。ボタンの文字は「← 戻る」のまま残る([[90_オーナーの判断事項]] の29番)。
- 利用者が一度ゴミ箱の一覧を見ると、以後はボタンに数が出なくなる。ゴミ箱の中身を実際に消した後も、ボタンは古い数を出し続け、利用者が押すと「ゴミ箱は空です」と出る([[90_オーナーの判断事項]] の58番)。
- BoomYack は、セーブパネルのゴミ箱の中身を識別子だけで覚えている。このため、保存先「ローカル」でゴミ箱に入れた保存済みのボードと同じ識別子の、保存先「サーバー」の保存済みのボードも、一覧に出なくなる。逆も同じである([[90_オーナーの判断事項]] の45番)。
- ゴミ箱に入った保存済みのボードを BoomYack が実際に消すのは、次のときである。
  - Jimbo のウインドウが見えなくなったとき(最小化したときや、ウインドウの再読み込みをしたときなど)
  - Jimbo を閉じるとき
- このとき、保存先「ローカル」の保存済みのボードは、保存先から消える。保存先「サーバー」の保存済みのボードは消えない([[90_オーナーの判断事項]] の25番)。
- BoomYack は、セーブパネルのゴミ箱の中身を、Jimbo の実行中だけ覚えている。
- 利用者が今ボードに開いている保存済みのボードをゴミ箱に入れても、ボードの中身とセーブパネルの現在名はそのまま残る。この後の上書き保存と Ctrl+S で起きることは、[[07d_データが消える条件の一覧]] と [[90_オーナーの判断事項]] の37番に書く。
