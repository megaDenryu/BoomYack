# 05 キー操作と元に戻す

状態: 草案(オーナー未承認)。索引と語の定義は [[利用者説明書 - 索引]]。

この文書は、BoomYack のキー操作の全部と、元に戻す操作・やり直す操作の対象を書く。付箋の入力欄の中だけで効くキー(Tab・Enter・かっこなど)は [[02_付箋]] の「入力の補助」に書く。

## キー操作が効く場所

BoomYack のキー操作は、効く場所によって次の3つに分かれる。

- ウインドウ全体で効くキーとは、キー入力の受け先が Jimbo のウインドウのどこにあっても効くキーのことである。
- 入力欄以外で効くキーとは、キー入力の受け先が入力欄(1行の入力欄・複数行の入力欄・書き込める領域)に無いときに効くキーのことである。Jimbo のほかの画面を開いているときも効く。
- ボードで効くキーとは、ボードがキー入力の受け先のときだけ効くキーのことである。利用者がボードの何もない所をクリックすると、ボードがキー入力の受け先になる。ほかの操作でボードがキー入力の受け先になるかどうかは確かめていない。

付箋の入力欄と付箋召喚の入力欄の中で利用者が押したキーは、上の3つのどれにも届かない。

## キー操作の一覧

| キー | 効く場所 | 結果 |
|---|---|---|
| Delete | 入力欄以外 | 選択されている配置物をすべて消す。付箋を消すと、つながっている矢印も消える |
| Ctrl+A、または Mac の Command+A | 入力欄以外 | ボード上のすべての配置物を選択する。ブラウザの「すべてを選択」は止める |
| Ctrl+C | ボード | 選択されている付箋をクリップボードへコピーする。選択に付箋が無いときは何もコピーしない。どちらの場合もブラウザのコピーは止める |
| Ctrl+V | ボード | クリップボードの中身を、見えている範囲の中心に当たる位置へ貼り付ける |
| Ctrl+Z | ボード | 元に戻す操作 |
| Ctrl+Shift+Z | ボード | やり直す操作 |
| Ctrl+Y | ボード | やり直す操作 |
| Ctrl+S | ウインドウ全体。ただし付箋の入力欄と付箋召喚の入力欄の中を除く。セーブパネルの名前の入力欄や、Fudaba の札の検索画面の入力欄の中でも効く | セーブパネルの現在名が決まっていないときは、セーブパネルを開く。現在名が決まっているときは、セーブパネルで今選んでいる保存先へ現在名で保存を始め、保存の終わりを待たずにお知らせ「(現在名)を上書き保存しました」を出す。保存先「サーバー」では、その後にサーバーの結果のお知らせが出る |
| Enter | セーブパネルで名前を変えている入力欄 | 名前の変更を確定する |
| Escape | セーブパネルで名前を変えている入力欄 | 名前の変更をやめる |

- BoomYack は、Ctrl+C・Ctrl+V・Ctrl+Z・Ctrl+Y・Ctrl+S では Ctrl キーだけを見る。Mac の Command キーでは、これらは効かない。
- BoomYack は、Ctrl+A と Ctrl+S では、押された文字が小文字の「a」「s」のときだけ反応する。このため、Caps Lock が有効なときや、Shift キーを一緒に押したときは、Ctrl+A と Ctrl+S は効かない。
- BoomYack は、Delete では修飾キー(Ctrl・Shift など)を見ない。修飾キーを一緒に押しても Delete は効く。
- Ctrl+S の保存とお知らせの詳しい振る舞いは [[07_保存と読み込み]] に書く。
- Delete・Ctrl+A・Ctrl+S は、Jimbo でボードのタブを開いていないときも効く([[90_オーナーの判断事項]] の16番)。
- Backspace キーで配置物を消すことはできない。
- Escape キーで閉じる物は無い。メニュー・セーブパネル・付箋の設定パネル・Fudaba の札の検索画面は、Escape キーでは閉じない。BoomYack が Escape キーを扱うのは、セーブパネルで名前を変えている入力欄だけである。
- セーブパネルの新規保存の名前の入力欄で Enter キーを押しても、保存されない。

## 元に戻す操作とやり直す操作

- 利用者は、元に戻す操作とやり直す操作を、ボードで効くキー(Ctrl+Z・Ctrl+Shift+Z・Ctrl+Y)でだけ行える。メニューには元に戻す操作の項目が無い。
- BoomYack は、最近の 100 回分までの操作を履歴に持つ。それより古い操作は元に戻せない。
- 利用者が履歴に加わる新しい操作をすると、それまでにやり直せた操作はやり直せなくなる。

### 元に戻す操作の対象になる操作

| 操作 | 1回分の単位 |
|---|---|
| メニューで付箋・矢印を作る | 作った1つ |
| 付箋召喚で付箋を作る | 作った1つ |
| 接続点をクリックして矢印を作る | 作った1本 |
| 貼り付けで付箋を作る | 貼り付けで作ったすべての付箋と矢印で1回分。これとは別に、付箋の間をつなぐ矢印が1本ずつ1回分として履歴に加わる([[90_オーナーの判断事項]] の17番) |
| AI の生成と分解で付箋を作る | 作ったすべての付箋と矢印で1回分。これとは別に、矢印が1本ずつ1回分として履歴に加わる |
| 配置物を消す | 1回の削除で消えたすべての配置物 |
| 付箋を動かす | 利用者がつかんだ付箋1つの移動。位置が変わらなかったときは履歴に加わらない |
| 付箋の文字を変える | 入力欄がキー入力の受け先でなくなったときに、受け先になったときと文字が違えば1回分 |
| 矢印のつまみ・線・曲線・中間点を動かす | 押した時点と放した時点で矢印の状態が違えば1回分。付箋につながった端や、その端に接する線をクリックしただけでも1回分が加わる([[03_矢印]] の「元に戻す操作との関係」) |

### 元に戻す操作の対象にならない操作

- 付箋の幅を変える操作
- 付箋の設定パネルでの変更
- Ctrl キーを押して付箋と一緒に動かした、ほかの配置物の移動
- 右クリックで折れ曲がりの点や中間点を足したり消したりする操作
- 音声入力で付箋に文字を足す操作。ただし、付箋の入力欄がキー入力の受け先になっている間に足した文字は、受け先でなくなったときの「付箋の文字を変える」の1回分に含まれるので、元に戻す操作で消える
- 付箋召喚から作った付箋を、そのまま押し続けて動かした移動
- 動かしている途中で2本目の指が触れて打ち切られた移動(画面では未確認。[[01_画面の構成と表示]] の「2本の指でつまむ操作」)
- 表示位置の移動と拡大・縮小
- 保存と読み込み

### 元に戻す操作の注意点

- 利用者が別の保存済みのボードを読み込んでも、BoomYack は元に戻す操作の履歴を消さない([[90_オーナーの判断事項]] の18番)。
- 削除を元に戻したとき、または付箋の追加をやり直したときの付箋の状態は [[90_オーナーの判断事項]] の12番で扱う。
- 矢印の変更を元に戻したとき、つながり方は元に戻らない([[90_オーナーの判断事項]] の15番)。
