# BoomYack 利用者説明書 - 索引

状態: 草案(オーナー未承認)

写した時点のコミット: BoomYack `1d693b0`(2026-09-30 にこのコミットのコードと突き合わせた。コードの部分は `c42d69e` から変わっていない。最初に写したのは `008f86b` である)

この説明書は、BoomYack の利用者から見た振る舞い(画面の文言・操作とその結果・データが保存される条件と消える条件)を、今のコードからそのまま写した文書である。この説明書には理想の振る舞いを書いていない。この説明書の作成者は、写す過程で見つけたおかしな振る舞いを、本文には今の振る舞いとして書き、仕組みの説明と直すかどうかの判断を [[90_オーナーの判断事項]] にまとめた。

この説明書の目的は、画面の座標とスクロールの扱いを作り直す予定の作業(表示の位置と倍率を1か所で持つ仕組みの導入)の前後で、利用者から見た振る舞いが変わらないことを確かめる基準にすることである。オーナーが承認した後は、この説明書が振る舞いの正本になり、コードと食い違ったときに誤っているのはコードの方になる。承認までは、この説明書は今のコードの写しであり、食い違ったら説明書を直す。

「(画面では未確認)」と書いた記述は、この説明書の作成者がコードを読んで導いたが、Jimbo の画面で操作して確かめていない記述である。この説明書の作成者がコードを読んでも決められなかった事柄は、本文に書かず、[[91_分からないこと]] にまとめた。

## この説明書で使う語

### 保存とセーブパネル

- 保存先とは、BoomYack が保存済みのボードを入れておく場所のことである。保存先には「ローカル」と「サーバー」の2つがある([[07a_保存先と保存の内容]] を参照)。
- 保存済みのボードとは、保存先に保存されている、ボード1枚分のデータのことである。
- セーブパネルとは、ボードの保存と読み込みを行う、見出しが「セーブ/ロード」のパネルのことである([[07b_セーブパネルの操作]] を参照)。
- セーブパネルのゴミ箱とは、セーブパネルで消した保存済みのボードを、実際に消すまでの間だけ入れておく所のことである。
- ボードの JSON ファイルとは、セーブパネルの「json」ボタンで書き出す、保存済みのボード1つ分のファイルのことである。
- 書式の版とは、ボードの JSON ファイルの中に書かれた、データの書き方の版を表す文字のことである。
- 配布版とは、利用者がインストールして使う形の Jimbo のことである。開発版とは、開発者が手元で開発用の道具から動かす形の Jimbo のことである。

### ボードと配置物

- ボードとは、付箋と矢印を並べる1枚の作業面のことである。この説明書で単に「ボード」と書くときは、Jimbo のウインドウに今出ている作業面を指す。セーブパネルでは「キャンバス」と呼ばれており、この説明書では画面の文言をそのまま書くときだけ「キャンバス」と書く。
- ボードの領域とは、Jimbo のウインドウの中で、ボードが占めている四角い範囲のことである。
- 見えている範囲とは、ボードの領域のうち、今ウインドウに映っている部分のことである。ボードの領域がスクロールしていないときは、ボードの領域全体と同じである。
- 配置物とは、ボードの上に置かれた付箋と矢印をまとめて呼ぶ語である。
- ボードの何もない所とは、付箋・矢印・メニュー・パネルのどれにも重なっていない、ボードの背景の部分のことである。
- 表示位置とは、ボードの中身を見えている範囲に対してどれだけずらして見せているかの量のことである。利用者がボードの何もない所を押して動かすと変わる。
- 表示の倍率とは、ボードの中身を拡大・縮小して見せている倍率のことである。起動したときは1倍である。
- 拡大・縮小の中心とは、表示の倍率を変えるときに、動かない基準として使う点のことである。BoomYack は、最後に拡大・縮小をした位置を拡大・縮小の中心として持ち続ける。
- 描画上の距離とは、表示の倍率を掛ける前の、ボードの中身の上での距離のことである。画面上の距離とは、描画上の距離に表示の倍率を掛けた、ウインドウに映った距離のことである。表示の倍率が1倍のときは、2つは同じである。
- 配置物の選択とは、配置物を操作の対象として印を付けた状態のことである。複数の配置物を同時に選択できる。この説明書で単に「選択」と書くときは、配置物の選択を指す。
- 範囲選択とは、入力欄の中の文字をマウスやキーで選んだ状態のことである。配置物の選択とは別の物である。
- グラフとは、矢印でつながった付箋のまとまりのことである。矢印の端が付箋につながっていれば、その付箋同士は同じグラフに入る。

### 付箋と矢印の部分

- つかむ枠とは、付箋の黄色い本体の外側を囲む、幅 30px の帯のことである。利用者はつかむ枠を押して付箋を動かす。
- 幅の帯とは、付箋の左右の外側の端にある幅 10px の細い帯のことである。利用者は幅の帯を押して付箋の幅を変える。幅の帯は、つかむ枠の左右の帯の外側 10px に重なっていて、つかむ枠より手前にある。利用者がその 10px を押すと、付箋は動かず、選択も変わらず、幅が変わる。
- 接続点とは、付箋の上下左右の外側にある、矢印の端をつなぐための青い丸のことである。
- 付箋召喚とは、ボードの上に常に1つだけある、付箋と同じ見た目の下書きの入力欄のことである([[02_付箋]] を参照)。
- 矢印のつまみとは、矢印の始点・終点・折れ曲がりの点・中間点に出る、丸や三角の印のことである。利用者は矢印のつまみを押して矢印の点を動かす。付箋の幅の帯とは別の物である。
- 付箋の識別子とは、1つのボードの中で付箋を見分ける文字の並びのことである。保存済みのボードの識別子とは別の物である。

### メニューとパネルとお知らせ

- ボードのメニューとは、ボードの何もない所で右クリックか長押しをすると出るメニューのことである。付箋のメニューとは、付箋を右クリックすると出るメニューのことである([[04_メニュー]] を参照)。
- 第1層とは、メニューの真ん中のマスを囲む8つのマスに並ぶ項目のことである。ボードのメニューの第1層は7つ、付箋のメニューの第1層は8つである。第2層とは、第1層の項目を押すと外側に出る、次の項目のことである。
- 削除のアイコンとは、ボードのメニューと付箋のメニューにある、配置物を消すためのゴミ箱の絵のアイコンのことである。セーブパネルの一覧の各行にある、保存済みのボードをセーブパネルのゴミ箱へ入れるためのゴミ箱の絵のボタンは、この説明書では「ゴミ箱へ入れるボタン」と呼ぶ。どちらもセーブパネルのゴミ箱とは別の物である。
- 検索パネルとは、Fudaba の札を探して札参照の付箋を作るための、見出しが「Fudaba札を貼り付け」のパネルのことである([[08_AIと音声入力とFudaba]] を参照)。
- お知らせとは、画面に数秒だけ出る短い文言の表示のことである。この説明書の作成者は、お知らせの文言を、コードにある文字列をかぎかっこで囲んでそのまま書く。
- 画面とは、Jimbo のウインドウに映っているもの全体のことである。Jimbo の中の機能の切り替えは「タブ」と呼ぶ。

### 名前と識別子と版番号

- セーブパネルの現在名とは、セーブパネルの「現在のキャンバス名」に出ている名前のことである。起動したときは決まっておらず、「（未保存）」と出る。
- ボードの内部名とは、BoomYack がボードのデータの中に持っている名前のことである。セーブパネルの現在名とは別に持たれており、食い違うことがある([[90_オーナーの判断事項]] の20番)。
- 保存済みのボードの名前とは、保存済みのボードのデータの中にある名前のことである。セーブパネルの一覧の各行に出る名前は、保存済みのボードの名前である。
- 識別子とは、保存先の中で保存済みのボードを見分ける文字の並びのことである。BoomYack はセーブパネルで保存するときに、セーブパネルの現在名から識別子を作る([[07a_保存先と保存の内容]] を参照)。
- 版番号とは、保存先「サーバー」の保存済みのボードが持つ、保存のたびに1つずつ増える番号のことである。お知らせの中では「revision」と表示される。
- 元に戻す操作とは、直前の操作を1回分取り消す操作のことである。やり直す操作とは、元に戻した操作をもう一度行う操作のことである。お知らせに付く「元に戻す」ボタンは、元に戻す操作とは別の物である。

### 入力

- 入力欄とは、利用者が文字を打ち込む欄のことである。1行の入力欄・複数行の入力欄・文字を書き込める領域を含む。この説明書で「付箋の入力欄」と書くときは、付箋の中の文字の入力欄(タイトル付きの付箋のタイトルと本文の欄を含む)を指す。
- キー入力の受け先とは、利用者がキーボードのキーを押したときに、そのキーを受け取る画面の中の1か所のことである。入力欄をクリックすると、その入力欄がキー入力の受け先になる。
- ポインタとは、画面の上でマウスの位置を示す矢印の印のことである。
- クリップボードとは、コピーした内容を一時的に置いておく、パソコン全体で共有される置き場のことである。
- JSON とは、データを文字で書き表す形式の1つのことである。BoomYack はボードの中身やグラフの形を JSON で書き出す。
- ドロップとは、ファイルをマウスで運んで、ボードの上で放す操作のことである。

### 外部との連携

- Jimbo とは、BoomYack を中に組み込んで使っているアプリのことである。BoomYack は Jimbo の「Board」のタブとして表示される。
- 宛先とは、BoomYack が Jimbo のサーバーなどへ依頼を送るときの送り先のことである。
- 状態番号とは、サーバーが依頼への応答に付ける、成功か失敗かを表す3桁の番号のことである。
- 外部とは、この BoomYack の画面以外で、保存先「サーバー」の保存済みのボードを変えるもの全体のことである。MCP と、別のウインドウで開いた Jimbo の BoomYack が外部に当たる。
- 更新通知とは、保存先「サーバー」の保存済みのボードが保存または削除されたことを、Jimbo のサーバーが BoomYack へ伝えるデータのことである。更新通知そのものは画面に出ない。BoomYack は更新通知を受けて、お知らせを出すことがある([[07c_サーバーとのやり取り]] を参照)。
- Fudaba とは、作業の札(課題や作業の単位)を管理する別の道具のことである。
- MCP とは、AI が Jimbo の外から保存先「サーバー」の保存済みのボードを読み書きするための接続口のことである。
- Claude とは、MCP を通して BoomYack のボードを読み書きする AI の1つのことである。
- LLM とは、文章を読み書きする AI のことである。付箋のメニューの項目名「LLM分解」に出てくる。
