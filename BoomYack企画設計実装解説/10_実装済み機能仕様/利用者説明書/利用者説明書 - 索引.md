# BoomYack 利用者説明書 - 索引

状態: 草案(オーナー未承認)

写した時点のコミット: BoomYack `c42d69e`(2026-09-30 にこのコミットと突き合わせた。最初に写したのは `008f86b` である)

この説明書は、BoomYack の利用者から見た振る舞い(画面の文言・操作とその結果・データが保存される条件と消える条件)を、今のコードからそのまま写した文書である。この説明書には理想の振る舞いを書いていない。写す過程で見つけたおかしな振る舞いは、本文では今の振る舞いとして書き、直すかどうかの判断を [[90_オーナーの判断事項]] にまとめた。

この説明書の目的は、画面の座標とスクロールの扱いを作り直す予定の作業(表示の位置と倍率を1か所で持つ仕組みの導入)の前後で、利用者から見た振る舞いが変わらないことを確かめる基準にすることである。オーナーが承認した後は、この説明書が振る舞いの正本になり、コードと食い違ったときに誤っているのはコードの方になる。承認までは、この説明書は今のコードの写しであり、食い違ったら説明書を直す。

本文で「(画面では未確認)」と書いた記述は、コードの流れから導いたが、Jimbo の画面で操作して確かめていない記述である。

## この説明書で使う語

### ボードと配置物

- ボードとは、付箋と矢印を並べる1枚の作業面のことである。この説明書で単に「ボード」と書くときは、Jimbo のウインドウに今出ている作業面を指す。セーブパネルでは「キャンバス」と呼ばれており、この説明書では画面の文言をそのまま書くときだけ「キャンバス」と書く。
- 保存済みのボードとは、保存先に保存されている、ボード1枚分のデータのことである。
- ボードの領域とは、Jimbo のウインドウの中で、ボードが占めている四角い範囲のことである。
- 見えている範囲とは、ボードの領域のうち、今ウインドウに映っている部分のことである。ボードの領域がスクロールしていないときは、ボードの領域全体と同じである。
- 配置物とは、ボードの上に置かれた付箋と矢印をまとめて呼ぶ語である。
- ボードの何もない所とは、付箋・矢印・メニュー・パネルのどれにも重なっていない、ボードの背景の部分のことである。
- 表示位置とは、ボードの中身を見えている範囲に対してどれだけずらして見せているかの量のことである。利用者がボードの何もない所を押して動かすと変わる。
- 表示の倍率とは、ボードの中身を拡大・縮小して見せている倍率のことである。起動したときは1倍である。
- 選択とは、配置物を操作の対象として印を付けた状態のことである。複数の配置物を同時に選択できる。
- グラフとは、矢印でつながった付箋のまとまりのことである。矢印の端が付箋につながっていれば、その付箋同士は同じグラフに入る。

### 付箋と矢印の部分

- つかむ枠とは、付箋の黄色い本体の外側を囲む、幅 30px の帯のことである。利用者はつかむ枠を押して付箋を動かす。
- 幅の帯とは、付箋の左右の外側の端にある幅 10px の細い帯のことである。利用者は幅の帯を押して付箋の幅を変える。幅の帯は、つかむ枠の左右の帯の外側 10px に重なっていて、つかむ枠より手前にある。このため、利用者がその 10px を押すと、付箋は動かず、選択も変わらず、幅が変わる。
- 接続点とは、付箋の上下左右の外側にある、矢印の端をつなぐための青い丸のことである。
- 付箋召喚とは、ボードの上に常に1つだけある、付箋と同じ見た目の下書きの入力欄のことである([[02_付箋]] を参照)。
- 矢印のつまみとは、矢印の始点・終点・折れ曲がりの点・中間点に出る、丸や三角の印のことである。利用者は矢印のつまみを押して矢印の点を動かす。

### メニューとパネル

- ボードのメニューとは、ボードの何もない所で右クリックか長押しをすると出るメニューのことである。付箋のメニューとは、付箋を右クリックすると出るメニューのことである([[04_メニュー]] を参照)。
- 第1層とは、メニューの真ん中のマスを囲む8つのマスに並ぶ項目のことである。ボードのメニューの第1層は7つ、付箋のメニューの第1層は8つである。第2層とは、第1層の項目を押すと外側に出る、次の項目のことである。
- セーブパネルとは、ボードの保存と読み込みを行う、見出しが「セーブ/ロード」のパネルのことである([[07_保存と読み込み]] を参照)。
- セーブパネルのゴミ箱とは、セーブパネルで消した保存済みのボードを、実際に消すまでの間だけ入れておく所のことである。
- 削除のアイコンとは、ボードのメニューと付箋のメニューにある、配置物を消すためのゴミ箱の絵のアイコンのことである。セーブパネルの一覧の各行にある、保存済みのボードをセーブパネルのゴミ箱へ入れるためのゴミ箱の絵のボタンは、この説明書では「ゴミ箱へ入れるボタン」と呼ぶ。どちらもセーブパネルのゴミ箱とは別の物である。
- お知らせとは、画面に数秒だけ出る短い文言の表示のことである。お知らせの文言は、コードにある文字列をかぎかっこで囲んでそのまま書く。

### 名前と識別子と保存

- セーブパネルの現在名とは、セーブパネルの「現在のキャンバス名」に出ている名前のことである。起動したときは決まっておらず、「（未保存）」と出る。
- ボードの内部名とは、BoomYack がボードのデータの中に持っている名前のことである。セーブパネルの現在名とは別に持たれており、食い違うことがある([[90_オーナーの判断事項]] の20番)。
- 保存済みのボードの名前とは、保存済みのボードのデータの中にある名前のことである。セーブパネルの一覧の各行に出る名前は、保存済みのボードの名前である。
- 識別子とは、保存先の中で保存済みのボードを見分ける文字の並びのことである。BoomYack はセーブパネルで保存するときに、セーブパネルの現在名から識別子を作る([[07_保存と読み込み]] を参照)。
- 版番号とは、保存先「サーバー」の保存済みのボードが持つ、保存のたびに1つずつ増える番号のことである。お知らせの中では「revision」と表示される。
- 元に戻す操作とは、直前の操作を1回分取り消す操作のことである。やり直す操作とは、元に戻した操作をもう一度行う操作のことである。

### 入力と外部

- 入力欄とは、利用者が文字を打ち込む欄のことである。この説明書で「付箋の入力欄」と書くときは、付箋の中の文字の入力欄(タイトル付きの付箋のタイトルと本文の欄を含む)を指す。
- キー入力の受け先とは、利用者がキーボードのキーを押したときに、そのキーを受け取る画面の中の1か所のことである。入力欄をクリックすると、その入力欄がキー入力の受け先になる。
- クリップボードとは、コピーした内容を一時的に置いておく、パソコン全体で共有される置き場のことである。
- JSON とは、データを文字で書き表す形式の1つのことである。BoomYack はボードの中身やグラフの形を JSON で書き出す。
- ドロップとは、ファイルをマウスで運んで、ボードの上で放す操作のことである。
- Jimbo とは、BoomYack を中に組み込んで使っているアプリのことである。BoomYack は Jimbo の「Board」の画面として表示される。
- Fudaba とは、作業の札(課題や作業の単位)を管理する別の道具のことである。
- MCP とは、AI が Jimbo の外から保存先「サーバー」のボードを読み書きするための接続口のことである。
- LLM とは、文章を読み書きする AI のことである。付箋のメニューの項目名「LLM分解」に出てくる。

## 出典の書き方

各節の末尾に、根拠にした主なファイルを「ファイル:行」の形で書く。ファイルの場所は次の略号で書く。

- `ui:` は BoomYack の `packages/ui/src/` を指す。
- `core:` は BoomYack の `packages/core/src/` を指す。
- `mcp:` は BoomYack の `packages/mcp/src/` を指す。

- `Jimbo-core:` は Jimbo の `packages/core/src/` を指す。
- `Jimbo-mcp:` は Jimbo の `packages/mcp-tools/src/` を指す。
- `SengenUI:` は Jimbo の `packages/electron-app/src/renderer/Packages/SengenUI/` を指す。
