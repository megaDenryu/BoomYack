# 06 コピーと貼り付けとファイル

状態: 草案(オーナー未承認)。索引と語の定義は [[利用者説明書 - 索引]]。

この文書は、配置物をクリップボードへコピーする操作、クリップボードから貼り付ける操作、ファイルへ書き出す操作、ファイルをボードへドロップする操作を書く。

## 付箋を文字にする規則

BoomYack は、コピーと書き出しで、付箋の中身を次の規則で1つの文字の並びにする。

| 付箋の種類 | 文字にした結果 |
|---|---|
| 自由テキスト | 入力欄の文字そのもの |
| タイトル付き | タイトル、改行、本文をつないだもの |
| 札参照 | 「[Fudaba札#(札の番号)]」 |

## コピー

コピーの操作は、次の表の2種類である。どちらの操作でも、BoomYack はクリップボードへ JSON の文字を書き込む。書き込む JSON には、付箋ごとの識別子と文字と、AI に読ませるための形の説明文が入る。付箋の位置・大きさ・設定と、矢印の形は入らない。

| 操作 | コピーする範囲 | 付箋のつながり |
|---|---|---|
| Ctrl+C、またはメニューの「コピー」 | 選択されている付箋(矢印は除く) | 入らない |
| メニューの「グラフをテキスト としてコピー」 | ボードのメニューでは、選択の並びの先頭の配置物(Ctrl+A の後は、ボードに最も早く置いた配置物)を含むグラフの付箋すべて。付箋のメニューでは、右クリックした付箋を含むグラフの付箋すべて | 入る。両端が付箋につながっている矢印ごとに、始点側の付箋から終点側の付箋へのつながりとして入る |

- 選択されている付箋が無いときは、Ctrl+C もメニューの「コピー」も、何もコピーしない。
- コピーしたとき、BoomYack はお知らせを出さない。

## 貼り付け

### 貼り付ける位置

- 利用者が Ctrl+V で貼り付けるとき、貼り付ける位置は、見えている範囲の中心に当たるボード上の点である。
- 利用者がメニューの「貼り付け」で貼り付けるとき、貼り付ける位置は、利用者が「貼り付け」の項目を押した位置である。

出典: `ui:基本オブジェクト/描画キャンバス/描画キャンバスView分解/クリップボード貼り付け.ts:37-44`、`ui:基本オブジェクト/キャンバス操作/座標変換/ボード基準座標変換.ts:41-43`

### 貼り付ける内容

BoomYack はクリップボードの文字を読み、その文字がグラフの JSON かどうかで振る舞いを変える。グラフの JSON とは、項目の並びを持ち、並びの各項目が識別子(文字)・文字・次の項目の識別子の並び・前の項目の識別子の並びを持つ JSON のことである(項目名は内部の名前 N9)。BoomYack のコピーで作った JSON は、グラフの JSON である。

#### クリップボードの文字がグラフの JSON のとき

- BoomYack は、並びの最初の項目から始めて、次の項目と前の項目をたどれる項目だけを自由テキストの付箋にする。最初の項目からたどれない項目は付箋にしない([[90_オーナーの判断事項]] の19番)。
- BoomYack は、ある項目の「次の項目」に書かれた項目ごとに、その項目の付箋から相手の付箋へ折れ線矢印を作る。
- BoomYack は、付箋の識別子に項目の識別子を使う。ボードに同じ識別子の配置物が既にあるときは、BoomYack は新しい識別子を使う。
- BoomYack は、作った付箋を木の形に並べる。ほかの付箋から矢印を受けていない付箋を最も上の並びとし、この並びを貼り付ける位置の高さに置き、貼り付ける位置から右へ並べる。矢印の先の付箋は、元の付箋の下端から 250px 下の並びに置く。横に並ぶまとまりの間は 350px 空ける。
- 項目の並びが空のとき、BoomYack は途中で処理をやめる。付箋は作られず、お知らせも出ない。

#### クリップボードの文字がグラフの JSON でないとき

- BoomYack は、クリップボードの文字全体を持つ自由テキストの付箋を1つ作る。付箋の本体の左上が貼り付ける位置に来る。
- クリップボードが空のときは、BoomYack は空の自由テキストの付箋を1つ作る。

#### クリップボードを読めなかったとき

- 何も起きない。BoomYack はお知らせも出さない。

## ファイルへの書き出し

ファイルへ書き出す操作は、次の表の2つである。どちらの操作でも、BoomYack はブラウザのダウンロードとしてファイルを保存する。

| 操作 | 書き出す中身 | ファイル名 |
|---|---|---|
| メニューの「グラフを JSON出力」 | ボードのメニューでは選択の並びの先頭の配置物を含むグラフ、付箋のメニューでは右クリックした付箋を含むグラフ。中身は「グラフをテキスト としてコピー」でクリップボードへ書く JSON と同じ | 「(ボードの内部名).graphtext.json」 |
| セーブパネルの一覧の各行の「json」ボタン | その行の保存済みのボード1つの全体(付箋・矢印の位置と形・表示位置を含む) | 「canvas_(保存済みのボードの名前)_(書き出した年月日)_(書き出した時分秒).json」 |

- 「グラフを JSON出力」のファイル名に使うのは、ボードの内部名である。ボードの内部名は、起動したときは「New Canvas」で、利用者がセーブパネルで保存したときにセーブパネルの現在名に変わる。利用者がボードを読み込んでも、ボードの内部名は変わらない([[90_オーナーの判断事項]] の20番)。
- 「json」ボタンのファイル名では、BoomYack は保存済みのボードの名前のうち `<>:"/\|?*` を `_` に置き換え、続いた空白を1つの `_` にまとめ、先頭から 50 文字までを使う。
- 「json」ボタンで書き出せたとき、BoomYack はお知らせ「JSONファイルをダウンロードしました」を出す。保存済みのボードが見つからないときは「キャンバスデータが見つかりませんでした」、書き出しに失敗したときは「JSON出力に失敗しました」を出す。保存の画面で利用者が保存を取り消しても、「JSONファイルをダウンロードしました」は出る(画面では未確認)。
- 「json」ボタンは、保存済みのボードを読み直す。このため、「json」ボタンは版番号と、保存先「ローカル」の形に合わないボードにも影響する([[07_保存と読み込み]] と [[90_オーナーの判断事項]] の40番・41番を参照)。

## ファイルをボードへドロップする

- 利用者が JSON のファイルをボードの何もない所へドロップすると、BoomYack はそのファイルを、ボード1枚分の保存データとして読む。
- 読めるファイルの条件は、次の5つをすべて満たすことである(項目名は内部の名前 N10)。
  1. 版・識別子・名前・作った日時・最後に保存した日時の項目が文字である。
  2. 版・識別子・名前が空でない。
  3. 表示位置の項目がある。
  4. 配置物の項目が並びで、配置物が 1000 個以下である。
  5. すべての配置物の種類が、付箋・折れ線矢印・なめらか矢印のどれかである。
- セーブパネルの「json」ボタンで書き出したファイルは、配置物が 1000 個以下なら、この5つの条件を満たす。
- 利用者が複数のファイルを一度にドロップすると、BoomYack は最初の1つだけを読み、残りは何も知らせずに無視する。
- 読めたとき、BoomYack はそのボードを保存先「ローカル」に、ファイルの中の識別子で保存する。「ローカル」に同じ識別子の保存済みのボードが既にあるとき、BoomYack は確認せずに置き換える。続いて BoomYack は、お知らせ「(保存済みのボードの名前)をローカルに保存しました」を出し、保存先を「ローカル」に切り替えてセーブパネルを開く。
- ファイルをドロップしても、ボードの中身は変わらない。ドロップしたボードを見るには、利用者がセーブパネルでそのボードを選んで読み込む。
- 読めなかったとき、BoomYack は何も知らせない([[90_オーナーの判断事項]] の21番)。
- BoomYack がブラウザの既定の動きを止めているのは、ボードの背景の上でのドロップだけである。付箋・メニュー・セーブパネルなどの上にファイルをドロップすると、Jimbo のウインドウがそのファイルの表示に切り替わり、保存していない変更が失われるおそれがある(画面では未確認。[[90_オーナーの判断事項]] の53番)。
