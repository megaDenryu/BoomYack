# 07d データが消える条件の一覧

状態: 草案(オーナー未承認)。索引と語の定義は [[利用者説明書 - 索引]]。

この文書は、利用者のデータが消える条件、置き換わる条件、中身が知らせなく変わる条件を1つの表にまとめたものである。この表を、データが消える条件の正本とする。ほかの文書は、この表を参照する。

- どの場合も、BoomYack は確認を出さない。
- 「補足」の欄の番号は、[[90_オーナーの判断事項]] の項目の番号である。

## 保存していない変更が失われる条件

| 条件 | 消える・置き換わるもの | 補足 |
|---|---|---|
| Jimbo を閉じる | ボードの保存していない変更 | |
| 別の保存済みのボードを読み込む | ボードの保存していない変更 | |
| 保存先を切り替えた後に、選んだままの行を「読込」で読み込む | 同じ識別子の別の保存済みのボードが読み込まれ、ボードの保存していない変更が失われる | 56番 |
| 付箋・メニュー・セーブパネルなどの上にファイルをドロップする | ボードの保存していない変更(ウインドウがファイルの表示に切り替わるおそれ) | 画面では未確認。53番 |
| Ctrl+R を押す | ボードの保存していない変更(ウインドウの再読み込みが起きる) | 画面では未確認。59番 |
| 読み込んだ後に、配置物を選び直さずに音声入力する | 聞き取った文字(ボードに無い付箋に入る) | 44番 |

## 保存済みのボードが置き換わる・消える条件

| 条件 | 消える・置き換わるもの | 補足 |
|---|---|---|
| 保存先「ローカル」で保存する | 同じ識別子を持つ保存済みのボード。名前が違っても、識別子に直すと同じになる名前(例: `a/b` と `a_b`)は同じ識別子になる | 新規保存と名前の変更は、同じ名前の保存済みのボードがあるときだけ断る |
| 保存先「ローカル」に知らない種類の配置物を持つ保存済みのボードがある状態で、新規保存か名前の変更をする | 一覧が空になるので同じ名前の確認ができず、同じ識別子の保存済みのボードを置き換える | 54番 |
| 読み込みに失敗した後に、保存先「ローカル」で保存する | 選んだ保存済みのボードの名前から作った識別子の保存済みのボード | 24番 |
| JSON のファイルをボードへドロップする | 保存先「ローカル」の、ファイルと同じ識別子の保存済みのボード | |
| 保存先「ローカル」の、決まった形に合わない保存済みのボードを読む | その保存済みのボード。一覧を読み直すだけでも消える | 41番 |
| セーブパネルのゴミ箱に何かが入ったまま、Jimbo のウインドウが見えなくなる・閉じる | 保存先「ローカル」の、ゴミ箱に入っている識別子の保存済みのボード | |
| 名前を変える | 古い名前の保存済みのボードがゴミ箱に入る。新旧の識別子が同じときは、名前を変えた後の保存済みのボードがゴミ箱に入る | 38番 |
| 別の保存先から読み込んだボードの名前を変える | 今の保存先にある、古い名前と同じ名前の別の保存済みのボードがゴミ箱に入り、「ローカル」ではウインドウが見えなくなった時点で消える | 38番 |
| 「json」ボタンを押した後に、読み込み直さずに保存先「サーバー」へ保存する | MCP などが保存済みのボードに加えた変更 | 40番 |
| ほぼ同時に2つの保存が保存先「サーバー」へ届く | 先に書いた方の変更 | 画面では未確認。57番 |

## 保存したつもりの中身が保存されない・後で消える条件

| 条件 | 消える・置き換わるもの | 補足 |
|---|---|---|
| セーブパネルのゴミ箱に入っている識別子へ保存する(開いているボードをゴミ箱に入れた後の上書き保存と Ctrl+S、ゴミ箱の保存済みのボードと同じ名前での新規保存と名前の変更、同じ識別子のファイルのドロップ) | 保存した中身。一覧に出ず、保存先「ローカル」ではウインドウが見えなくなった時点で消える | 成功のお知らせは出る。37番 |
| 保存先「ローカル」への保存が失敗する | 保存しようとした中身 | 成功のお知らせが出る。42番 |
| 保存先「サーバー」で、版番号の食い違いで保存を断られる | 保存しようとした中身(成功のお知らせも出るので、利用者が気づかずに閉じると失われる) | 22番 |
| 保存先「サーバー」で、ファイル名が同じになる別の名前(日本語だけの名前どうしなど)で保存する | 保存しようとした中身(保存を断られる) | 成功のお知らせも出る。39番・22番 |
| 版番号を覚えている保存済みのボードが外部で消された後に保存する | 保存しようとした中身。再起動するまで保存できない | 成功のお知らせも出る。43番 |
| サーバーが受け付ける上限を超える大きさのボードを、保存先「サーバー」へ保存する | 保存しようとした中身(一度も保存できない) | 成功のお知らせも出る。上限の値は画面では未確認。55番 |

## 中身が知らせなく変わる条件

| 条件 | 変わるもの | 補足 |
|---|---|---|
| 保存済みのボードを保存し直す | 保存される作った日時が、その回の起動の時刻に置き換わる | 20番 |
| 読み込んだ後に元に戻す操作をして、そのまま保存する | 前のボードの配置物が今のボードに混ざって保存される | 画面では未確認。18番 |
| 消した付箋の接続点があった場所に矢印の端を放して、保存する | 存在しない付箋へのつながりが保存される。読み込み直すと、そのつながりは知らせなく捨てられる | 画面では未確認。14番 |
| タイトルに改行があるタイトル付きの付箋で、文字の変更を元に戻すか、音声入力で文字を足す | タイトルの2行目以降が本文へ移る | 31番 |
| 配置物を消す | 選択していた配置物と、つながっていた矢印 | 元に戻す操作で配置物は戻るが、付箋の中身は戻らない(画面では未確認。12番)。右クリックした付箋ではない配置物が消えることがある(11番) |
