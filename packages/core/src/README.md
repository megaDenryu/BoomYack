# @boomyack/core

DOM / SengenUI 非依存の純粋ドメイン層である (tsconfig の lib から DOM を外して機械的に強制している)。

実装済み:

- `保存形式/` — 保存JSONの正典と version migration 層 (issue #3)。読み込みの入口は `保存JSONから最新版ボードを読み込む` の 1 関数で、旧版 (text付箋・まっすぐ矢印・middlePoints省略) は最新版へ移行され、不正データは型付きの失敗になる。書き込み側は `最新版ボードJSON` 型の値だけを永続化する
- `ボード操作/` — UI/MCP 共通の操作境界 `ボード操作サービス` (issue #4) と revision による楽観ロック (issue #5)。永続化は `ボード保存リポジトリ` インターフェースで抽象化し、実装・ID生成・時刻・変更通知先は利用側がコンストラクタで注入する。編集は `ボード編集コマンド` (判別共用体) の列を 1 回の保存で適用し、途中で失敗したら保存しない。全書き込みは expectedRevision の照合を通る。UI の全量保存 (キャンバス全体の JSON) も `ボード全体を置き換える` / `新規ボードとして全量保存する` で同じ照合を通る
- `ボード操作/ボード変更通知.ts` — 保存・削除の成功を外部へ伝える契約 (issue #8)。輸送方式 (SSE 等) には依存しない
- `AI向けボードAPI/` — 保存 JSON を見せない要約と、一時キーによるグラフ一括追加 (issue #6)

公開境界は `index.ts` である。

注意: このパッケージから `packages/ui` (描画層) を import してはならない。依存の向きは ui → core の一方向である。
